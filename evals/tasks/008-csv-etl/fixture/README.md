# Exportação de clientes

`data/customers.csv` é a exportação semanal do CRM. Colunas: `name`, `email`, `country`, `amount`
(valor total comprado, em euros). Codificação UTF-8, separador vírgula, primeira linha é o cabeçalho.

O ficheiro vem sujo: espaços a mais, emails em maiúsculas, clientes repetidos, países em falta
e valores que não são números.
