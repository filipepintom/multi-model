Este repositório é uma ferramenta de despesas pessoais que fui fazendo nos tempos livres: uma linha de comandos (`python -m expenses ...`) para registar, importar e exportar despesas, e um relatório mensal que também se vê no browser com `expenses serve`. Começou por ser só para mim, mas neste momento já a usam mais umas cinco pessoas da equipa, cada uma com a sua base de dados, e há mais gente a pedir. Antes de a partilhar com mais pessoas quero ter a certeza de que dá para confiar nela.

Queria uma auditoria ao projeto inteiro: se as contas e os relatórios estão certos, se há riscos de segurança agora que já não sou o único a usá-la e se o código está em condições de ser mantido por mais alguém além de mim.

Não alteres código. O que preciso é de uma lista de problemas reais, com a prova de cada um, ordenada pelo que devo corrigir primeiro. Prefiro poucos problemas bem demonstrados a uma lista enorme de palpites.
