Herdámos esta API da loja online de outra equipa e queremos pô-la em produção dentro de algumas semanas. Antes disso precisamos de uma auditoria ao código: correção (o que pode dar resultados errados), segurança e manutenção.

Queremos no fim uma lista de problemas priorizada, que possamos transformar em backlog, com o ficheiro e a linha de cada um, um cenário concreto em que o problema se manifesta e o que propões para o corrigir. Prefiro poucos problemas bem fundamentados a uma lista longa de suspeitas.

Não alteres o código nesta fase: só queremos o diagnóstico. O README explica a estrutura e as regras de negócio, e os testes existentes passam com `npm test`.
